# C++ Practical Assignment 5

## Practical Title
Classes and Objects, This Pointer, Inline Function, Static Member Function and Friend Class.

## Objectives
- Understand classes and objects in C++.
- Understand the uses of the this pointer.
- Implement inline member functions.
- Understand static data members and static member functions.
- Use a friend class to access private members.

## Technologies Used
- Programming Language: C++
- IDE: Dev-C++
- Libraries: iostream, string

## Concepts Implemented
1. Classes and Objects
2. Constructors and Destructors
3. This Pointer
4. Function Chaining
5. Inline Functions
6. Static Data Members
7. Static Member Functions
8. Friend Classes

## How to Run
1. Open Dev-C++.
2. Open the `main.cpp` file.
3. Click Execute → Compile.
4. Click Execute → Run.
5. Enter a roll number, name and marks.

## Sample Input
```text
46 Riyansh 72.5
```

## Expected Results
- Displays student details.
- Demonstrates the this pointer.
- Demonstrates function chaining.
- Checks pass/fail status.
- Counts the number of Student objects.
- Demonstrates access to private members through a friend class.
- Adds grace marks and displays the updated result.

## Conclusion
This practical demonstrates the implementation of classes and objects, the this pointer, inline functions, static members and friend classes in C++.
